# Gallery captions

Screenshots of the public demo (demo data, fictional farm), taken on 2026-10-21 at a 3:2 size (1500x1000; image 4 at 1600x1067; image 8 at 1200x800). One line per image, 160 characters or fewer.

1. `01_smart-display-home.png`: Smart display: five starter tiles. The Alexa+ screen is simulated; the server behind it is real.
2. `02_daily-briefing-judge-view.png`: Daily briefing card, health items first. Judge view puts the English under each Telugu line. Demo data.
3. `03_sale-plan.png`: Sell-day plan card with the answer in Telugu and English. The price is simulated, and the farm is fictional.
4. `04_health-check-result.png`: Health check result: urgency set by code, guidance for the vet, no diagnosis or dose. One sentence starts it; no questions. Demo data.
5. `05_record-read-back.png`: Record the day: the numbers are read back first. Nothing is saved until the farmer says yes.
6. `06_smart-speaker-mode.png`: Smart speaker mode: voice only, no screen. The answer is also written in the transcript.
7. `07_developer-panel-mcp.png`: Developer panel: the real MCP tools/call request and response behind one answer, from the public demo.
8. `08_architecture.png`: Architecture: the Alexa+ screen and cards are simulated or sandboxed; the MCP server and its 14 tools are real. Nova is off in the demo.
9. `09_tests-and-ci.png`: README test line (3,486 tests) and the CI run summary of the commit pushed just before: four jobs passed, macOS manual and skipped.

Known crops: the health check card (image 4) is taller than the simulated screen and scrolls, so its lower part is cut. The transcript box scrolls and shows the end of a long answer.

Not included: the Telugu farmer phone page. It needs the pilot settings, a token and a farm file, and the pilot link is never public.
